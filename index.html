CUSTOM MC TITLE

Custom MC Title is a personalized Minecraft Bedrock title project created for TRIALS SMP. It focuses on giving the server its own identity through custom on-screen title messages, helping make important moments, announcements, and server events more recognizable. Designed to complement the TRIALS SMP experience, this project adds a personalized touch to the way players see and experience the server.
